# STORE LISTING (draf, boleh edit sebelum publish)

## Nama
Steal a Kebun 🌱 [BETA]

## Deskripsi singkat
Tanam kebun sultanmu, curi tanaman teman (atau jaga baik-baik!), dan buru 10 harta
karun teka-teki. Rebirth, mutasi Rainbow, event Hujan Kopi tiap Sabtu!

## Deskripsi panjang
🌱 Tanam 22 tanaman unik dari Cabai Noob sampai Kopi Gacor Abadi
🔒 Kunci basemu, curi yang termahal dari teman (adil: 3 detik channel + cooldown)
🗺️ Pecahkan 10 teka-teki, ikuti kompas, gali harta dengan sekop
🌈 Mutasi Gold/Dark/Rainbow hingga x10 income
♻️ Rebirth untuk multiplier permanen
🎁 Daily reward + kode redeem + event mingguan

## Kontrol
PC: WASD + E (curi/gali). Mobile: joystick + tombol aksi.

## Kebijakan
Game dalam beta: progres bisa di-reset saat update besar. Pembelian bersifat donasi
kosmetik/kenyamanan, bukan investasi dan tidak menjanjikan penghasilan.
