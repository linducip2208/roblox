# GDD 1-pager — Steal a Kebun (aktual kode 9 Nov 2026)

**Fantasi:** jadi sultan kebun, pamer item Secret, jambret punya teman.
**Session:** 5-10 mnt, idle-friendly.
**Map:** 8 plot melingking + tengah shop + Trade Plaza (no steal zone, `SafeZoneName = "TradePlaza"`).
**Ekonomi aktual:** 22 item (20 + 2 Event-only `kopi_hujan`/`payung_raksasa`);
restock shop 5 mnt (bobot rarity, Secret tidak masuk shop);
rebirth basis 1 jt SKALA LINEAR (syarat = 1 jt x (rebirths+1)), reward +1x multiplier max 10x.
**Update Sabtu:** event katalog 4 (`hujan/golden/rush/meteor`), auto Sabtu 19:00 WIB 30 mnt + trigger admin `;event`.
**Win condition:** koleksi Secret + leaderboard rebirth.
**Anti-bosan:** steal cooldown 5 dtk, lock 60 dtk (+10/rebirth, +10 VIP), channel 3 dtk / 15 stud, revenge notif.
