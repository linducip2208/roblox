# GDD 1-pager — Steal a Kebun

**Fantasi:** jadi sultan kebun, pamer item Secret, jambret punya teman.
**Session:** 5-10 mnt, idle-friendly.
**Map:** 8 plot melingkar + tengah shop + Trade Plaza (no steal zone).
**Ekonomi:** restock shop 5 mnt, pity legendary 1/100, rebirth 1jt cash = x2.
**Update Sabtu:** 2 item baru + 1 event (Hujan Kopi x2 luck 30 mnt).
**Win condition:** koleksi Secret + leaderboard rebirth.
**Anti-bosan:** steal cooldown 5s, lock 60s, revenge notif.
